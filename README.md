# Kashta Kala Carpenter App

## About the Project
Kashta Kala is an Android app made for carpenters.  
This app helps carpenters to calculate furniture cost, calculate area, and see furniture design catalog.

This project is created using Kotlin in Android Studio.

## Features
- Calculate furniture cost
- Calculate area using length and width
- Show furniture design catalog
- Easy and simple to use

## Technology Used
- Kotlin
- Android Studio
- Android SDK

## Screens in App
- Home Screen
- Cost Calculator
- Area Calculator
- Catalog Screen
- Result Screen

## How to Run
1. Open Android Studio
2. Open Kashta Kala project
3. Sync Gradle
4. Click Run button
5. Run on emulator or Android phone

## Project Purpose
The purpose of this app is to help carpenters:
- Calculate work cost quickly
- Reduce calculation mistakes
- View furniture designs easily
- Support self-employment
